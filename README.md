# PhotoFilter

O projeto `PhotoFilter` é um editor de imagem com operações de processamento de imagem básico.

## Objetivos

Inicialmente este foi um trabalho feito para a matéria de `processamento de imagens`, o objetivo deste trabalho é realizar uma refatoração completa no projeto.

- [] Frontend Refactor
- [] Backend Refactor
- [] Utilizar WebAssembly ao invés da API.
